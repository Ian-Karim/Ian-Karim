## 👨‍💻 Sobre mí

Soy **Ingeniero en Informática** egresado de **UPIICSA-IPN (México 🇲🇽)** con enfoque en **Desarrollo Web Full-Stack y Aseguramiento de Calidad (QA)**.

Me apasiona construir software completo, seguro y bien probado: desde el modelado de bases de datos relacionales y la arquitectura backend, hasta interfaces responsivas, automatización de pruebas y despliegue en contenedores.

- 🚀 **Enfoque principal:** Desarrollo Full-Stack (`PHP 8`, `Java / Spring Boot`, `JavaScript ES6+`) y QA Automation.
- 🛡️ **Calidad y Seguridad:** Pruebas unitarias, E2E y de carga, además de mitigación de vulnerabilidades **OWASP Top 10**.
- 🤖 **Intereses actuales:** Integración de APIs REST con flujos de IA (`Langflow`), `Docker` y desarrollo Full-Stack moderno.
- 🌱 **Aprendiendo ahora:** Java avanzado (`MOOC.fi Java Programming II`) y arquitectura de sistemas escalables.
